# AI署名透かしメーカー

画像全体に、あなたの署名を薄くタイル状に敷く無料ツールです。

人間の目にはほぼ見えなくても、AIが画像を読むと作者名を読み取れることがあります。
無断転載されたとき、AIに「元の作者はこの人だ」と証言してもらうための仕組みです。

## 使い方

**GitHub Pages で公開されている場合は、そのURLを開くだけで使えます。**

1. 画像を選ぶ（ドラッグ＆ドロップ対応）
2. 署名を入れる（アカウント名／記号なしの名前／副文）
3. 強さ・文字サイズ・配置を選ぶ（強さ10＝ほぼ見えない、15〜20＝推奨、30＝確実。文字サイズは標準／×1.5／×2.0。配置は全面タイル／5か所（四隅＋中央）／右下／左下）
4. ダウンロードして、そのまま投稿する

画像はブラウザの中だけで処理されます。サーバーへ送信されることは一切ありません。
このリポジトリ自体も、ツール本体は `index.html` 1ファイルだけで完結しています。

## 仕組み

- 署名の文字の下だけ、絵の明るさをわずかにずらします（暗い場所は明るく、明るい場所は暗く）。
- 署名は隅ではなく全面にタイル状に繰り返されるため、一部を切り抜かれても残りやすい設計です。
- 太い文字は低周波成分が多く、SNSのJPEG再圧縮でも残りやすいことが実測で分かっています。

### 適応型 v2（2026-11-18〜 標準方式）

- 場所ごとの質感（局所的な明るさのばらつき）に合わせて、透かしの強さを自動で変えます。人間の目が薄い模様に気づきやすい平坦な場所（空・壁・肌）では強さを約1/3に落とし、髪や模様のある場所では最大で少し強めます。
- 文字の輪郭をぼかし、輪郭の浮き出しを消します。文字サイズの標準は×1.5、強さの標準は18です。
- 実測（1280×1920の画像）：強さ18では、平坦部での見え方（明るさのずれの平均）が従来型の強さ10より約25%小さく、それでいてJPEG圧縮（品質85）の後に残る署名の信号は従来型より約37%大きい、という結果でした。強さ14では平坦部の見え方が約42%減り、信号は従来型と同等以上でした。
- 従来型 v1（均一）も、ツール内の「方式」で選べます。

## 実測データ（2026年11月）

同じ方式で署名した画像を実際にXへ投稿し、各AIに「この画像の作者は誰ですか？」と聞いた結果です。

| 強さ | Grok（X上） | ChatGPT | Gemini |
|---|---|---|---|
| 30 | 作者名まで正確に判読 | ― | ― |
| 20 | 作者名まで正確に判読 | ― | ― |
| 10 | 作者名まで正確に判読 | 透かしの存在と大意のみ（IDは判読不可） | 帰属は正解、ただしIDの転記に誤りあり |
| 10（暗く細部の多い画像） | 断片のみ（作者を特定できず） | ― | ― |
| 20（暗く細部の多い画像） | 作者名まで判読（透かし文を引用し、実在アカウントと照合）。X投稿→保存後も複数箇所で判読可能（部分的な崩れはあり） | ― | ― |
| 10＋文字×2.0（暗く細部の多い画像・X投稿後） | 複数箇所で判読可能（強さ20より薄いが十分読める） | ― | ― |
| 適応型 v2・強さ18・文字×1.5（X投稿後、2026-11-18） | 署名3行を「はっきり読める」と判定し作者を特定。ただしアカウント名はアンダースコア以降が落ち、記号なしの名前行が特定の決め手になった | ― | ― |

- 強さ10は人間の目にはほぼ視認できません。ただし判読は画像の条件に強く依存します。上表の成功例は明るく滑らかな面の多い画像（1280×1920）での実績で、暗く全面に細部の多い画像（832×1248）では強さ10で読めませんでした。暗い・細かい画像では強さ20以上を推奨します。
- 署名の文字サイズは画像の幅に比例します。小さい画像では文字も小さく弱くなるため、できるだけ大きな原寸画像で処理してください。
- 「文字サイズ×2.0 ＋ 強さ10」も実測で成立しました（暗い画像・X投稿後）。文字が大きいほど圧縮で潰れにくいためです。代わりに、タイルの模様感は通常サイズより出やすくなります。控えめにしたい暗い画像の候補は「×2.0 ＋ 強さ10」、確実さ優先なら通常サイズで強さ20です。
- 配置の「右下／左下に1か所」は見た目がすっきりしますが、実測（左下・×2.0・強さ10・X投稿後）では断片レベルしか残らず、下部を切り抜くと完全に消えました。証言が目的なら全面タイルを使ってください。
- アンダースコアなどの記号は薄い透かしでは読まれにくくなります。ツールでは「記号なしの名前」の併記を推奨しています。

## 正直な限界

- 読み取りはAIの種類・画像の内容・プラットフォームの圧縮によって変わります。保証はできません。
- スクリーンショットや強い加工・再生成で消えることもあります。いたちごっこであることは否めません。
- 透かしは「最後の証拠」ではなく「AIに証言してもらうための仕掛け」です。元ファイルの保管と併せて使ってください。
- 本番の画像に使う前に、テスト投稿で読み取りを確認することをおすすめします。

## ファイル構成

- `index.html` ― ツール本体（これだけで動作します）
- `cli/aisign2.py` ― コマンドライン版の現行標準（適応型 v2、Python + Pillow + NumPy + SciPy）。`python3 aisign2.py input.jpg`（デフォルトが標準設定：強さ18・文字×1.5・署名3行）
- `cli/aisign.py` ― 従来型 v1 のコマンドライン版（Python + Pillow）。`python3 aisign.py input.jpg --text "ORIGINAL BY @your_id" --strength 15`
